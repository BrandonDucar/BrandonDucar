### Persistent AI agents that remember, recover, and prove their work

Most agent demos end when the chat ends. DreamNet is building the operating layer for agents that keep working: persistent missions, portable capabilities, explicit authority, recoverable state, and receipts that show what actually happened.

## What DreamNet can do

- Run persistent agents and fleets that recover from context loss and process restarts.
- Package instructions, tools, policy, memory references, and evaluations into portable Capsules.
- Route work across local models, cloud providers, agent runtimes, and human approval gates.
- Train and test agents against versioned tool-use contracts before assigning real work.
- Coordinate specialist agents through bounded delegation, quorum review, and escalation.
- Produce content-addressed evidence and receipts for builds, decisions, tests, and deployments.
- Connect local, cloud, and edge execution without making any single vendor the source of truth.
- Turn repositories, documents, conversations, and live signals into governed working context.

## The operating pattern

```text
Objective
  -> bounded DreamLoop
  -> capability Capsule
  -> authorized tools and models
  -> execution
  -> verification
  -> receipt
  -> durable memory and recovery
```

DreamLoops govern behavior. Capsules carry capability. ToolGym verifies mastery. Receipts prove execution. Humans retain authority over consequential actions.

## Public proof, private core

The production DreamNet monorepo and internal orchestration remain private. The repositories above are intentionally scoped public specifications, clean-room implementations, and runnable product wedges. They show the contracts and evidence model without publishing private prompts, credentials, customer data, swarm topology, or proprietary lifecycle systems.

## Building now

- **Warper Keeper:** portable, shareable working context for people and agents.
- **Memory Weaver:** local-first source consolidation, provenance, and durable context maintenance.
- **DreamNet Hopper:** policy-aware routing across the AI resources a team already owns.
- **DreamNet Discover:** search and AI-visibility intelligence powered by the same governed agent layer.

The near-term goal is straightforward: make autonomous work persistent, inspectable, portable, and useful in the real world.
